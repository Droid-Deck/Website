        Set up in four steps

        1. Check your device

          You need Android 9 or newer and about 3 GB free. Add 1.1 GB for the desktop and emulators.

        2. Install the APK

          Download it from GitHub Releases and open it. Android asks you to allow the install.

        3. Install the Linux runtime

          DroidDeck downloads it the first time you open it. Stay on Wi-Fi.

        4. Press Play and sign in

          Steam opens in Gaming Mode. Sign in, then install a game.

        On Android 14 or newer?

        Turn on "Disable child process restrictions" in Developer options. On Android 12 and 13, Steam's first launch shows a "Fix it for me" button.

        Stuck?

        Ask on Discord. For bugs, post in #bug-reports with the zip from Share logs.

        FAQ

        Is DroidDeck free?

        Yes. It is free and open source under GPL-3.0, with no ads and no telemetry.

        Which devices run it?

        Anything on Android 9 or newer. It runs best on Adreno 730 and newer. Mali, Xclipse, PowerVR and older Adreno chips are experimental.

        Do I need root?

        No. On Android 14 or newer you flip one switch in Developer options. The setup guide shows which one.

        Does it work on Mali, Exynos or MediaTek?

        It starts on many of them, but support is experimental. Some games crash or show a black screen. Fixes reach Preview builds first.

        Is it on the Play Store?

        Not today. Get the APK from GitHub Releases. Android may warn you about installing outside the store, which is normal.

        Is there an iPhone version?

        No. DroidDeck is Android only.

        Is it safe to sign in to Steam?

        You sign in inside the real Steam client, the same one a Steam Deck runs. All of DroidDeck's code is public.

        Do online games with anti-cheat work?

        Mostly not. Games that need kernel anti-cheat will not go online. Some Easy Anti-Cheat games can still be played offline.

        My game runs slowly. What can I try?

        Lower the in-game settings first, then try a newer graphics driver in DroidDeck's settings. The performance HUD shows what is holding the game back.

        Can I install games on an SD card?

        Yes. Set External storage as the default under Setup > Storage, then install. Games you already have stay where they are.

        Do controllers work?

        Yes. Built-in controls, Bluetooth and USB pads all work, and you can pair several for split screen. There are touch controls too.

        How do I get fixes early or report a bug?

        Preview builds are in the app under Updates > Preview. For bugs, post in #bug-reports with the zip from Share logs.

        Watch out for fake sites

        Copycat websites are using the DroidDeck name, and some get a lot of visitors. None of them are ours. Don't download anything from them.

        Report a fake site to Google
        • The address bar says droid-deck.dev.
        • Every download button opens github.com/Droid-Deck.
        • DroidDeck is free. We never ask for payment, a sign-up or a survey.
